## Validation and known limits

Existing recorded application validation reports **93 host assertions**, **311 UI assertions at 130% font size**, and lint with no errors. These are recorded build results, not tests run by this public documentation repository. Publication preparation also confirmed installation of 0.2.10/build 12 in a test emulator. No physical-phone testing was performed for this publication.

Android supplies only eligible calls to the default screening app. Optional Contacts access is needed for saved contacts to participate. SMS filtering, complete system call history, call-log removal, and voicemail control are not provided or guaranteed. See [usage](../usage.md#android-limits).

Older Call Harbor identifiers install separately. JSON migrates rules/settings while preserving the receiving app's current Activity. Older history and private snapshots remain with the older installation. Export before uninstalling.
