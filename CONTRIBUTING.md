# Contributing

This repository maintains public documentation, screenshots, support forms, and release guidance. Application source is private and is not accepted here.

Documentation corrections, accessibility improvements, reproducible reports, and focused feature requests are welcome. Open an issue before substantial proposals. For a correction, submit a focused pull request explaining the problem and verification.

Before submitting:

1. Read [support](SUPPORT.md), [security](SECURITY.md), and [licensing](docs/licensing.md).
2. Keep application source, source ZIPs, builds, keys, personal data, backups, and device evidence out of Git. Completed install APKs belong in Release assets.
3. Use relative links and descriptive alt text. Follow [screenshot guidance](docs/screenshots.md#capture-guidance).
4. Describe observed behavior and distinguish testing releases from stable releases.
5. Require passing GitHub repository checks and manually review rendered links/images. These checks validate this repository, not the Android application.

Preserve existing proprietary terms and separate third-party licenses. Contributions do not imply a new license grant.
