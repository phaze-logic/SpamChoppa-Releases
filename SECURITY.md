# Security policy

## Private reports

Email [phazecrypto@gmx.com](mailto:phazecrypto@gmx.com) with subject `SpamChoppa security report`. Do not disclose vulnerabilities or sensitive data in public issues.

Include affected version, Android version, impact, and minimal reproduction using synthetic data. Do not send signing keys, passwords, device credentials, full backups, contacts, or real call history. Coordinate disclosure with the maintainer after a fix is available.

## Versions and downloads

The documented release is **0.2.10**, a development-signed, debuggable **testing prerelease**. No stable release or long-term support schedule is declared. Check [Releases](https://github.com/phaze-logic/SpamChoppa-Releases/releases) for availability and signing status.

Download only official release APKs and [verify SHA-256](docs/installation.md#verify-the-download). Checksums detect mismatches but do not independently authenticate a publisher. Android APK signatures govern package identity/update compatibility. The app does not download updates itself.

See [privacy](docs/privacy.md) for local data, JSON exports, and app-lock limits.
