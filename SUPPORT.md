# Support

Read [troubleshooting](docs/troubleshooting.md) and [release notes](docs/releases/0.2.10.md) first.

For bugs/features, use [GitHub Issues](https://github.com/phaze-logic/SpamChoppa-Releases/issues/new/choose). For private support, email [phazecrypto@gmx.com](mailto:phazecrypto@gmx.com) with subject `SpamChoppa support`. Report vulnerabilities through [SECURITY.md](SECURITY.md).

Include installed version/build from About, Android version/device model, permission/default-screening status, reproduction steps, expected behavior, and actual behavior. Use invented numbers for matching examples. State whether the result came from **Test a number** or a real incoming call.

Public issues/attachments are visible to everyone. Do not upload backups, personal numbers, contacts, real call history, credentials, or unredacted phone screenshots. Share the minimum redacted information needed.

The current release is for testing. No response-time or long-term support commitment is declared.
